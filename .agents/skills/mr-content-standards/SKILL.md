# Purpose

Ensure all content adheres to:

- Evidence-forward tone
- Opinion clearly labeled
- Updated date present
- Sources required for factual claims
- No marketing language
- No supplement promotional tone
- No absolute certainty when evidence is mixed

# Structural Requirements

## Topic Pages Must Include:

- Evidence Snapshot
- What we know
- What we don't know
- My interpretation (clearly labeled)
- Key takeaways
- References

## Insights Must Include:

- Content type label
- Primary topic
- At least 1 source unless clearly marked Opinion

## Policy Notes Must:

- Separate facts from value judgments
- State tradeoffs clearly
- Include citations for factual claims

If required elements are missing, halt and request correction.
